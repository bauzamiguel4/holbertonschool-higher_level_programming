# Python - ABC (Abstract Base Classes)

This project explores Object-Oriented Programming (OOP) concepts in Python, focusing heavily on Abstract Base Classes (ABCs), interfaces, duck typing, method overriding, and subclassing standard library components.

## Learning Objectives
- Understand and apply Abstract Base Classes (ABCs) using Python's `abc` module.
- Enforce interface completeness in derived classes via `@abstractmethod`.
- Implement custom behavior through inheritance and method overriding.
